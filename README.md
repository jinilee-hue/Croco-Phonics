# Croco Phonics (악어 이빨 파닉스)

두 명이 번갈아 악어 이빨을 누르는 파닉스 보드게임. **레벨 N = FPR K 교재 Lesson N**: 그 레슨의 음가와 그 레슨 쪽에 나오는 단어로 한다.
레벨 1은 Lesson 1(p.9–20)의 m 단어, 레벨 2는 Lesson 2(Short a)… 지금 레벨 1–10(Unit 1–2, Lesson 1–10).

## 규칙
1. 라운드가 시작되면 그 레벨의 단어 하나가 **지시 단어**로 나온다(화면 위 카드 · 왼쪽 위에서 입을 계속 덥석거리는 악어 얼굴 배지 = 이 단어는 덥석). 그 레벨 음가(공식 FPR K 녹음) + 단어를 들려준다.
   배지는 게임 속 3D 악어를 정면에서 입을 여닫는 11장면으로 렌더해 오린 움직이는 WebP(1.16초마다 한 번 덥석, 눈은 제자리·아래턱이 내려감;
   `tools/make_bite_badge.py` → `assets/img/bite_croc.webp`, 414×431). 얼굴과 초록 아래턱만 그린다(몸통·다리는 숨기고,
   아래턱은 다리 없는 몸통을 아래에서 둥글게 마감한 `badgeChin` — 잘린 가장자리 없음).
   흰 테두리와 붉은 그림자는 크롬이 프레임마다 한 번 그려 이미지 안에 넣어 둔다(움직이는 이미지에 CSS 그림자 필터를 걸면
   크롬이 턱이 움직일 때 이전 장면의 그림자를 지우지 못해 잔상이 남았다). 도구가 출력하는 `.bite` 위치·크기를 css에 그대로 쓴다.
   악어 얼굴을 고치면 다시 실행.
2. 이빨 10개(앞 4 + 양옆 3)에 그 레벨 단어가 하나씩 숨어 있고, 지시 단어는 딱 한 이빨에만 있다(단어가 10개보다 적은 레벨은 다른 단어를 다시 섞어 채운다).
   이빨·소리 버튼의 글자는 그 레벨 글자(m, a, s …)이고, 카드 단어에서 그 글자가 주황색으로 강조된다(첫 글자, 짧은 모음 레벨은 가운데 모음: C**a**t).
3. 이빨을 누르면 → 그림카드가 튀어나오고 → **음가 + 단어**를 들려주고 → "Now say the word." → 마이크로 아이 목소리가 들리면 칭찬 → 카드는 누른 사람 쪽에 쌓이고 → 상대 턴.
4. 지시 단어가 숨은 이빨을 누르면 이빨이 보라색으로 빛나고 악어가 **덥석!** 그 사람이 지고, 상대가 이긴다.
   덥석 뒤 입에서 튀어나온 큰 카드로 **걸린 단어의 음가와 단어를 한 번 더 읽어 준다**(글자·단어가 차례로 통통) → 결과 화면.
5. 결과 화면 버튼 두 개: **다시 하기**(같은 레벨, 새 지시 단어) · **다음 레벨 →**(다음 레슨의 음가와 단어. 진 사람이 먼저).
   다음 레벨을 누르면 악어가 입을 닫았다 열며 이빨 글자가 바뀌고, "Level 2!" 배너에 새 글자(Aa)가 나오며 그 음가를 들려준 뒤 새 판이 시작된다.
   마지막 레벨에서는 다음 레벨 버튼이 없다. 게임 화면 왼쪽 위 로고 밑에 "Level 2 · Short a" 표시.
   세로 화면에서는 두 버튼이 위아래로 놓인다(나란히 두면 아래 구석의 플레이어를 가림).
   **레벨별 누적 승리**: 플레이어마다 이름표 옆에 레벨 칩(그 레벨 글자 · 왕관 · 이긴 판 수, 예: Mm 👑2 · Aa 👑1). 이길 때마다 그 레벨 칩이 톡 커지며
   +1, 지금 레벨 칩은 금색 테두리, 0승은 흐리게. 두 플레이어 모두 같은 레벨 칩을 가진다. 접속해 있는 동안 쌓이고 새로고침하면 처음부터.
   결과 버튼은 칩 줄 위에 놓인다.
   다시 접속하면 레벨 1부터. 주소 `?level=N` 으로 레벨 N부터 시작할 수 있다(예: http://127.0.0.1:5211/?level=3).

## 인트로(타이틀 화면)
- 흐름(매직블록 인트로처럼): 페이지가 열리면 **타이틀이 먼저 등장**한다(로고가 떨어지고, 악어가 커지고, 그림카드가 날아오고, START).
  잠시 뒤 **악어가 게임을 설명**한다. 이때 START 대신 오른쪽 아래에 **Skip**(건너뛰기)이 나오고 로고·카드는 잠시 비킨다.
  설명이 끝나거나 Skip을 누르면 **다시 타이틀과 START**가 나오고 악어가 "Press start to play!". **START를 누르면 게임 시작**
  (설명에 쓴 지시 단어로 첫 판). 설명이 시작되기 전에 START를 누르면 바로 게임. 게임에서 나가기 버튼으로 돌아오면 설명 없이 START가 있는 타이틀.
- 타이틀의 글자는 레벨 글자 하나가 아니라 **여러 레벨 글자**(m a p s t n i c f d): 이빨마다 다른 글자(앞니 m a p s t), 그리고 점토 글자들이
  **악어를 가운데 두고 빙글빙글** 돈다(할리갈리 시작 화면 카드처럼, `orbitFrame`). 뒤쪽은 작게 악어 뒤로 숨고 앞쪽은 크게(앞 글자 19u ≈ 1728×960에서 높이 180px, 뒤는 0.4배),
  링은 할리갈리처럼 악어 허리께에서 돈다: 앞쪽은 앞니 발치 아래(앞 글자가 이빨을 가리지 않음), START 뒤를 지날 땐 흐려져 사라지고
  가로 화면에선 화면 아래로 조금 나갔다 들어온다. 뒤쪽은 악어 머리 뒤.
  가끔 하나씩 톡 뛰며 한 바퀴 돈다. 떠다니는(위아래) 움직임은 없다. 설명과 게임에서는 모든 이빨이 그 레벨 글자, 도는 글자는 숨김.
- 오른쪽 위 **나가기**(문 + 화살표, 소리 버튼 옆)는 타이틀에도 있다: 게임·결과 → 타이틀, 타이틀 → 게임을 연 페이지로 돌아감
  (매직블록과 같음: 뒤로 가기, 혼자 열린 탭이면 닫기, 안 되면 처음부터).
- 설명 순서: 인사 → 지시 단어 카드(위 가운데에 크게 → 게임 때와 같은 자리로) → 번갈아 누르기(장갑 손이 이빨을 누름) → 카드가 나오면
  말하기 → 지시 단어 이빨이면 보라색 + 덥석 → "Ready? Let's play!".
- 설명 화면은 단순하게: 악어·말풍선·지시 단어 카드만 남기고 로고·START·장식·플레이어는 숨긴다.
- 악어 등장: 로딩이 끝나면 반 바퀴 돌며 커지고(튀지 않음) 입을 벌린다.
- 주소 옵션: `?nohowto` = 설명 없이 바로 타이틀(QA 스크립트용), `?target=map` = 지시 단어 고정(QA).
- 말풍선은 악어 머리 옆에 뜨고 카드·아바타·로고·버튼은 가리지 않는다. 말하는 동안 윗턱이 말하듯 천천히 움직인다.

## 언어 EN | 한
- 위쪽 오른쪽 기본 버튼 줄의 국기 토글(매직블록과 같은 모양). 고른 언어는 기억한다(localStorage `croco.lang.v1`).
- 바뀌는 것: 악어 설명(말풍선 + 음성), 게임 중 악어 대사(차례·말해 봐·칭찬·앗·승리·한 번 더), 화면 글자(플레이어·차례·승리·다시 하기·다음 레벨·레벨·건너뛰기).
  단어·음가·레슨 이름(Short a 등)은 항상 영어. 설명 중에 바꾸면 그 줄을 바로 다른 언어로 다시 말한다.
- 한국어 글꼴: Jua(매직블록과 같음) — 쓰는 글자만 잘라 `css/font-ko.css`에 내장(`tools/make_ko_font.py`, 한국어 문구를 바꾸면 다시 실행).

## 화면 배치
- 위: 왼쪽 로고, 가운데 지시 단어 카드, 오른쪽 EN|한 · 소리 · 나가기. 아래 양쪽 구석: 플레이어(아바타 + 모은 카드).
- 차례 표시는 그 플레이어에게 직접 붙는다: 아바타 바로 위에 그 플레이어 색(1 파랑 · 2 주황)의 "Your turn!"/"네 차례!" 말풍선.
  꼬리가 얼굴을 가리키고, 차례마다 아바타에서 톡 튀어나온다. 상대 플레이어는 흐리게 표시된다(`tools/qa/qa_turn.py`로 꼬리 위치 실측).
- 말해 보기 마이크는 화면 가운데, 악어 아래턱(앞니 아래 빨간 입술)에 겹쳐 나온다(`placeMic` → `jawScreen`).

## 실행
- `실행.command` 더블클릭 → http://127.0.0.1:5211/ (마이크는 http(s) 또는 파일에서 허용 필요)
  서버는 `tools/serve.py`(캐시 안 함: 고친 뒤 그냥 새로고침해도 최신 파일이 보임).
- `index.html` 더블클릭(file://)도 동작 (음성·폰트는 js/css에 내장).
- 테스트 훅: `window.__test = { mic:false | heard:true, target:'moon', teeth:[...] }`, `window.__croco`(LEVELS, setLevel, levelUp …), 주소 `?nohowto` · `?target=` · `?level=`.
- QA(`tools/qa/`): `qa_flow`·`qa_sizes`·`qa_again`·`qa_file`·`qa_cards`(카드 비행)·`qa_tutor`(페이지 열리면 설명 → START 타이틀 → 게임, 홈, EN|한, Skip, 마이크 위치, 긴 단어)·`qa_levels`(레벨마다 음성·카드·이빨 글자, 다음 레벨·다시 하기·마지막 레벨)·`qa_wins`(덥석 뒤 음가+단어 다시 읽기 순서, 레벨별 승리 칩 개수·겹침 3사이즈)·`qa_tutor_voice`(설명 음성: 소리 잠김 때 말풍선 시간, 첫 터치에 지금 줄부터 읽기, tut1–8 순서·말풍선 글자 일치·겹침 없음, 한국어)·`qa_intro_letters`(타이틀 이빨·도는 글자 10개·앞이 뒤보다 큼·화면 안, 레벨 5 설명/게임은 p, 나가기 게임→타이틀·타이틀→이전 페이지)·`console`(SDF 경고).
  QA는 `window.__ready && window.__intro`(등장 모션 끝)를 기다린 뒤 START를 누른다.

## 구성
- `js/croc.js` — 3D 악어(three.js). 악어 이빨 장난감 모양(몸통 없음 · `design/croc_ref.png`)을 SDF로 만든 무광 클레이 모델:
  윗턱(경첩) 덥석, 이빨 눌림, 눈 깜빡/시선(눈은 Phonics Match 튜터처럼 갈색 홍채 + 반짝이),
  캐릭터 시트의 표정을 눈으로 — 안전한 이빨이면 신난 눈(^^), 지시 단어 이빨이면 놀란 눈.
  게임 화면에서는 카메라가 위로 올라가고 입을 더 벌려 이빨 10개가 다 보인다.
  입 안 입체감: 만들 때 한 번, 악어 자체 SDF로 정점마다 앰비언트 오클루전(오목한 곳·닿는 곳일수록 어둡게)을 구워 정점 색에 넣는다
  (`bakeAO`, 실행 중 비용 없음, 빌드 +40 ms). 입천장은 예전 밝은 분홍(#d98880) 그대로에 목구멍 근처만 살짝 진하게(#b5545b) + 약한 AO
  (진한 밤색 입천장은 납작한 어두운 벽처럼 보이고 혀 위 벽에 혀 모양 그림자가 뚜렷이 생겨 되돌림), 이빨 안쪽 바닥은 더 진한 빨강에 뒤로 갈수록 어둡게,
  이빨은 잇몸 닿는 곳(윗니는 뿌리 쪽)이 살짝 어둡다. 앞쪽 산호색 테두리는 밝은 그대로. 윗잇몸(윗니가 나오는 띠)도 아래 잇몸처럼 밝은 산호색:
  아래를 향해 그늘에 있어 칠만으로는 절반 밝기라, 그 띠에만 약한 자체 발광(0.25)을 줘 렌더 밝기를 아래 잇몸과 맞췄다(타이틀 L 134/143, 게임 146/137). 혀는 예전처럼 한 가지 산호색(음영 넣은 혀는 사용자가 되돌림).
  윗턱의 초록 피부 ↔ 입 안(입술 띠·입천장) 경계는 픽셀 단위로 가른다(`hoodPick`: 정점마다 피부색·입 안 색·부호 있는 값 `aSel`을 두고
  셰이더가 0에서 자름). 정점 색만으로는 입술 띠 가장자리가 삼각형 따라 톱니처럼 번지고 입꼬리에 붉은 조각이 생겼다. 옆벽에서 0.1 안쪽은 옆벽(초록)으로 쳐서
  입술 띠가 입꼬리 옆벽에서 깔끔하게 끝난다(레퍼런스 그림처럼 옆벽 안쪽은 초록).

## 음성
회사 TTS 소년 목소리(Qwen3 'aiden') = Magic Block과 같은 목소리. 레벨 단어는 Magic Block 음성, 없으면 Phonics Island의 같은 목소리 단어 음성을,
레벨 음가는 공식 FPR K 녹음(Magic Block에서 다듬은 것, 없으면 Phonics Island에 있는 원본을 같은 방식으로 다듬음)을 쓴다. 공용 대사도 Magic Block에서 재사용.
한국어(`k:`)는 매직블록의 한국어 공용 대사를 재사용한다(블럭이라고 말하는 great1만 뺌).
게임 전용 새 대사(인사·규칙·덥석·레벨 업, 악어 튜터 설명 `tut1`–`tut8`)는 영어(`NEW`)·한국어(`NEW_KO`) 모두 **회사망에서** 아래로 생성:
```
zsh -ic '/Users/jini/.hermes/bin/uv run --with numpy python tools/build_voice.py'
```
(새 대사가 없으면 게임은 그 대사만 건너뛰고 진행한다. "Now say the word."/"이제 단어를 읽어 봐."·"Uh-oh!"/"앗!"처럼 기존 음성이
 대사 일부를 말해 주는 줄은 그 음성을 쓴다.) 2026-11-09 회사 TTS로 전부 생성(대사 12개 × 영·한 + 위 단어 9개).
- 확인: 만든 음성은 Whisper(medium)로 다시 받아 적어 글자와 맞는지, 군소리(웃음·반복)가 없는지 본다. TTS는 같은 입력을 늘 똑같이 읽으므로
  틀린 것은 지시문 바꾸기(`TAKE_OF`: k:chomp 웃음, t:tut7 "Jump", k:tut6 끝말, w:sip "zip")나 입력 바꾸기(`TEXT_OF`: pit→`Pit.`
  — "cut"으로 읽힘, paint→`Paint` — "pink", sip→`Sip`)로 고친다.
- 설명 음성: 브라우저는 첫 터치 전엔 소리를 못 내므로, 페이지를 열자마자 나오는 설명은 말풍선만 읽을 시간만큼 띄운다. 설명 중 화면을
  한 번 누르면(버튼 말고) 소리가 켜지면서 지금 말풍선부터 바로 소리 내어 읽는다. 홈에서 돌아온 타이틀은 첫 터치 때 인사(hello).
