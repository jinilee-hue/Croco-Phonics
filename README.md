# Croco Phonics (악어 이빨 파닉스)

두 명이 번갈아 악어 이빨을 누르는 파닉스 보드게임. 단어는 모두 **FPR K · Unit 1 · Lesson 1(교재 p.9–20)** 에 나오는 m 단어.

## 규칙
1. 라운드가 시작되면 m 단어 하나가 **지시 단어**로 나온다(화면 위 카드 · 빨간 '깨물기' 배지). 음가 /m/ + 단어를 들려준다.
2. 이빨 10개(앞 4 + 양옆 3)에 Lesson 1 m 단어가 하나씩 숨어 있고, 그중 하나가 지시 단어다.
3. 이빨을 누르면 → 그림카드가 튀어나오고 → **/m/ 음가 + 단어**를 들려주고 → "Now say the word." → 마이크로 아이 목소리가 들리면 칭찬 → 카드는 누른 사람 쪽에 쌓이고 → 상대 턴.
4. 지시 단어가 숨은 이빨을 누르면 이빨이 보라색으로 빛나고 악어가 **덥석!** 그 사람이 지고, 상대가 이긴다.
5. Play Again → 새 지시 단어로 다음 판(진 사람이 먼저).

## 인트로(타이틀 화면)
- 등장 모션: 로딩이 끝나면 로고가 위에서 떨어지며 자리 잡고, 악어가 반 바퀴 돌며 커지고(튀지 않음) 입을 벌린다.
  옆 그림카드는 할리갈리 카드처럼 양옆에서 날아 들어오고, 글자가 톡톡 나타난 뒤 START가 나온다. 홈 버튼으로 돌아와도 다시 나온다.
- **게임 설명(악어 튜터 · 매직블록처럼 접속할 때마다 첫 START에서)**: 인트로 화면에서 악어가 말풍선으로 설명하고, 끝나면 게임 화면으로 넘어간다.
  같은 접속 안에서 다시 하기·홈 → START를 누를 때는 설명 없이 바로 게임이 시작된다.
  인사 → 지시 단어 카드(위 가운데에 크게 → 게임 때와 같은 자리로) → 번갈아 누르기(장갑 손이 이빨을 누름) → 카드가 나오면 말하기
  → 지시 단어 이빨이면 보라색 + 덥석 → "Ready? Let's play!" → 게임(설명에 쓴 지시 단어로 첫 판 시작).
- 설명 화면은 단순하게: 악어·말풍선·지시 단어 카드만 남기고 로고·START·장식·플레이어는 잠시 숨긴다. 오른쪽 아래에 **Skip**(건너뛰기) 버튼.
  주소 뒤에 `?howto`를 붙이면 START를 누를 때마다 설명한다(예: http://127.0.0.1:5211/?howto). QA 훅: `window.__test.howto = true`.
- 말풍선은 악어 머리 옆에 뜨고 카드·아바타·로고·버튼은 가리지 않는다. 말하는 동안 윗턱이 말하듯 천천히 움직인다.

## 언어 EN | 한
- 위쪽 오른쪽 기본 버튼 줄의 국기 토글(매직블록과 같은 모양). 고른 언어는 기억한다(localStorage `croco.lang.v1`).
- 바뀌는 것: 악어 설명(말풍선 + 음성), 게임 중 악어 대사(차례·말해 봐·칭찬·앗·승리·한 번 더), 화면 글자(플레이어·차례·승리·다시 하기·건너뛰기).
  단어와 /m/ 음가는 항상 영어. 설명 중에 바꾸면 그 줄을 바로 다른 언어로 다시 말한다.
- 한국어 글꼴: Jua(매직블록과 같음) — 쓰는 글자만 잘라 `css/font-ko.css`에 내장(`tools/make_ko_font.py`, 한국어 문구를 바꾸면 다시 실행).

## 화면 배치
- 위: 왼쪽 로고, 가운데 지시 단어 카드, 오른쪽 EN|한 · 소리 · 홈. 아래 양쪽 구석: 플레이어(아바타 + 모은 카드).
- 차례 표시는 그 플레이어에게 직접 붙는다: 아바타 바로 위에 그 플레이어 색(1 파랑 · 2 주황)의 "Your turn!"/"네 차례!" 말풍선.
  꼬리가 얼굴을 가리키고, 차례마다 아바타에서 톡 튀어나온다. 상대 플레이어는 흐리게 표시된다(`tools/qa/qa_turn.py`로 꼬리 위치 실측).
- 말해 보기 마이크는 화면 가운데, 악어 아래턱(앞니 아래 빨간 입술)에 겹쳐 나온다(`placeMic` → `jawScreen`).

## 실행
- `실행.command` 더블클릭 → http://127.0.0.1:5211/ (마이크는 http(s) 또는 파일에서 허용 필요)
  서버는 `tools/serve.py`(캐시 안 함: 고친 뒤 그냥 새로고침해도 최신 파일이 보임).
- `index.html` 더블클릭(file://)도 동작 (음성·폰트는 js/css에 내장).
- 테스트 훅: `window.__test = { mic:false | heard:true, target:'moon', teeth:[...], howto:true }`, `window.__croco`.
- QA(`tools/qa/`): `qa_flow`·`qa_sizes`·`qa_again`·`qa_file`·`qa_cards`(카드 비행)·`qa_tutor`(인트로 모션·설명·EN|한·Skip·첫 판만·마이크 위치·긴 단어)·`console`(SDF 경고).
  QA는 `window.__ready && window.__intro`(등장 모션 끝)를 기다린 뒤 START를 누른다.

## 구성
- `js/croc.js` — 3D 악어(three.js). 악어 이빨 장난감 모양(몸통 없음 · `design/croc_ref.png`)을 SDF로 만든 무광 클레이 모델:
  윗턱(경첩) 덥석, 이빨 눌림, 눈 깜빡/시선(눈은 Phonics Match 튜터처럼 갈색 홍채 + 반짝이),
  캐릭터 시트의 표정을 눈으로 — 안전한 이빨이면 신난 눈(^^), 지시 단어 이빨이면 놀란 눈.
  게임 화면에서는 카메라가 위로 올라가고 입을 더 벌려 이빨 10개가 다 보인다.
- `js/sdf.js` — SDF + Surface Nets 메셔. `js/stage.js` — 카메라·조명·그림자·피킹.
- `js/game.js` — 진행(지시 단어 → 턴 → 공개/말하기/수집 → 덥석/결과). 카드는 할리갈리처럼 움직인다: 이빨에서 뒷면으로 나와 포물선을 그리며 들렸다가 공중에서 뒤집혀 앞면으로 내려앉고,
  모을 때는 다시 들려 포물선으로 날아가 카드 더미 위에 사뿐히 놓인다(`flyer().fly`).
  긴 단어(mushroom 등)는 카드 안쪽 폭에 맞춰 글자를 줄인다(`wordFit`: 게임 글꼴로 실측, 말하기 강조 1.12배까지 여유). `js/audio.js` — 음성·효과음·배경음·마이크.
- `js/fx.js` — 반짝이·별·색종이·보라 폭발.
- 배경음악: 직접 합성한 신나는 루프(`tools/make_bgm.py` → `assets/audio/bgm.mp3` + `js/bgm-data.js`): F장조 132 BPM 16마디 약 29초.
  스틸드럼 멜로디, 통통 튀는 베이스, 엇박 우쿨렐레 코드, 킥·박수·하이햇·봉고, 8마디마다 필인. 매직블록과는 다른 곡과 코드.
  루프 이음매 없음. 게임 안 음량은 예전 곡과 같은 수준(-22.7 dBFS, 예전 -23.2)이고 목소리가 나올 때는 줄어든다.
- 에셋: `assets/img/logo.webp`·`bg.webp`(다운로드의 `croco_logo.png`·`croco_bg.png` → `tools/import_art.py`로 다시 가져옴), `hand.webp`(다른 파닉스 게임의 장갑 손, 대기 힌트), `crown.webp`(매직블록의 3D 왕관, 이긴 사람 머리 위), `p1/p2.webp`(게임 화면 레퍼런스의 아바타 · `tools/crop_avatars.py`), `assets/cards/`, `assets/voice/`.

## 음성
회사 TTS 소년 목소리(Qwen3 'aiden') = Magic Block과 같은 목소리. 단어 12개, 공식 FPR K /m/ 음원, 공용 대사는 Magic Block에서 재사용.
한국어(`k:`)는 매직블록의 한국어 공용 대사를 재사용한다(블럭이라고 말하는 great1만 뺌).
게임 전용 새 대사(인사·규칙·덥석, 악어 튜터 설명 `tut1`–`tut8`)는 영어(`NEW`)·한국어(`NEW_KO`) 모두 **회사망에서** 아래로 생성:
```
zsh -ic '/Users/jini/.hermes/bin/uv run --with numpy python tools/build_voice.py'
```
(새 대사가 없으면 게임은 그 대사만 건너뛰고 진행한다. 튜터 설명은 말풍선만 읽을 시간만큼 띄운다.
 "Now say the word."/"이제 단어를 읽어 봐."·"Uh-oh!"/"앗!"처럼 기존 음성이 대사 일부를 말해 주는 줄은 그 음성을 쓴다.)
